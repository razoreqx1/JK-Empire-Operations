GA Build 259 | Version 359 | 2026-08-21

GENERAL AVAILABILITY - STANDALONE DOCK AND UI

Build 259 promotes the exact live-proven Build 258 runtime to GA while keeping EOC as one installation and preserving every prior EOC feature and the developer documentation.

- Removes EOC's hidden dependency on an optional shared UI color table so every EOC tab can render in a standalone session.

- Adds self-contained access through Dock Interactions.
- Packages the Docked-menu replacement through X4's required substitution catalog so the game loads it without another UI installation.
- Preserves callbacks already registered by installed UI add-ons when Docked-menu ownership changes.
- Continues accepting callbacks registered after EOC loads so the shared menu remains cooperative.
- Retains a bounded startup retry only; adds no watcher, polling, per-frame work, recurring scan, gameplay authority, or save migration.
- Preserves Raw Scrap exclusion, the retired pinwheel, all Build 253 runtime features, and all Build 254 documentation.

Build 259 / version 359 is the EOC 3.2 GA release. Build 257 is superseded by its confirmed tab-rendering failure; Build 258 remains the preserved live-tested candidate source.
