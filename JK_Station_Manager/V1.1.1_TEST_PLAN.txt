JK Empire Operations v1.1.1 - Issue Engine Test Plan
====================================================

Safety
------
This release remains advisory-only. It does not alter stations, ships, trade rules,
wares, assignments, or save dependencies. The extension ID and save="0" remain unchanged.

Test 1 - Load and menu
----------------------
1. Install over the existing JK Empire Operations folder.
2. Load the save and wait about 12 seconds.
3. Open Empire Operations with Ctrl+H.
4. Confirm the main menu and all existing pages open normally.

Test 2 - NEW to ACTIVE
----------------------
1. Open Advisor Recommendations and open a WHY page.
2. On the first scan for that leading issue, confirm STATUS is NEW and AGE is 1 scan.
3. Select Refresh Analysis without fixing the issue.
4. Reopen WHY and confirm STATUS is ACTIVE and AGE increased.
5. Confidence should progress LOW -> MEDIUM -> HIGH over consecutive scans.

Test 3 - Storage IMPROVING
--------------------------
1. Find the leading storage-pressure issue shown by the advisor.
2. Reduce that ware's amount, but keep it at or above 90 percent capacity.
3. Refresh Analysis.
4. Confirm the storage WHY page shows IMPROVING.
5. Refresh again with the amount unchanged or rising; it should return to ACTIVE.

Test 4 - RESOLVED memory
------------------------
1. Clear either the leading empty-resource condition or leading storage-pressure condition.
2. Refresh Analysis.
3. Open Advisor Recommendations.
4. Confirm LAST RESOLVED appears with the issue type and lifetime in scans.

Test 5 - Debug log
------------------
Search debuglog.txt for [JKSM][V111]. Expected lifecycle entries include:
- ISSUE_CREATED
- ISSUE_UPDATED
- ISSUE_RESOLVED

Report any XML/load error, frozen menu, missing value, or lifecycle result that does not match.
