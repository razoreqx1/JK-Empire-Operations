# JK Empire Operations Center (EOC)

A governance-first operations layer for X4: Foundations.

## Current release

- Version: 2.2 GA
- Release build: 144
- X4 compatibility: 8.x / 9.x
- Steam Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3778882957

## Highlights

- Full EOC management window from **Dock Interactions > OPEN EXECUTIVE OPERATIONS CENTER** in the Personal Office.
- Separate EOC pinwheel navigation; EOC does not register or intercept Ctrl+H.
- Named fleet-production templates created entirely inside EOC.
- Partial, case-insensitive blueprint search by ship name or hull identifier.
- Preview a fleet at one compatible player shipyard or distribute it across compatible owned shipyards.
- Separate Preview and Confirm actions with duplicate-order protection.
- Owned blueprints, X4-generated loadouts, normal shipyard resources, and native captain/crew lifecycle.
- Deliberate one-ship logistics ordering with Medium/Large choice where both are valid.

## First-time access

1. Load the game and wait about 10 seconds for EOC initialization.
2. In the Personal Office, open **Dock Interactions** using the icon immediately to the right of Diplomacy.
3. Select **OPEN EXECUTIVE OPERATIONS CENTER**.

## Installation

Copy `JK_Station_Manager` into the X4 `extensions` directory, or subscribe through Steam Workshop. Do not add another folder between `extensions` and `JK_Station_Manager`.
