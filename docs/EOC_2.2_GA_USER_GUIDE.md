# EOC 2.2 GA User Guide

## Open EOC

1. Load the game and wait about 10 seconds for initialization.
2. While in the Personal Office, open **Dock Interactions** using the icon immediately to the right of Diplomacy.
3. Select **OPEN EXECUTIVE OPERATIONS CENTER** to open the full management window directly.

EOC does not use Ctrl+H. The separate EOC pinwheel remains available through EOC navigation and return paths.

## Build a saved fleet

1. Open **Fleet & Logistics** and select **Fleet Management**.
2. Create or edit a named fleet template.
3. Use the search field to find owned blueprints. Search is partial and case-insensitive, and matches ship names or hull identifiers.
4. Add ship types and bounded quantities.
5. Choose **One Compatible Shipyard** or **Spread Across Compatible Shipyards**.
6. Select **Preview Fleet Build** and review every planned ship and yard. Preview places no orders.
7. Select **Confirm: Build This Fleet** only when the plan is correct.

After confirmation, EOC locks repeat submission and reports how many native X4 tasks were accepted. Player shipyards control resources, scheduling, construction, captains, and crew.

## Order one logistics ship

In **Fleet & Logistics**, select **Does a station need a ship?** EOC offers Medium and/or Large only when you own a valid blueprint and a compatible owned yard can build it. Size choice, Preview, and Confirm remain separate actions. Exactly one ship is submitted after confirmation, and duplicate station-and-cargo orders remain blocked.

## Safety boundaries

- No free ships or resource bypass.
- No vanilla ship-configuration screen.
- No automatic or repeating production.
- Owned blueprints and compatible player shipyards only.
- X4-generated loadouts and native captain/crew lifecycle.
- Preview never submits an order.
- Confirmation is always deliberate.
