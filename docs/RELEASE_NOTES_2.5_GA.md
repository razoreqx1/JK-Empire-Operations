# EOC 2.5 GA — Build 173

## Station health and focused cases

- Chronic stations now explain every retained issue contributing to their current status.
- Each contributor shows its evidence, history, significance, and recommended next action.
- Players can create one issue-specific investigation directly from the station health inventory without duplicates.
- Opening Cases with a working station now selects that station automatically and hides unrelated stations until **All Stations** is deliberately chosen.

## Required interface framework

EOC requires [UI Extensions and HUD](https://steamcommunity.com/sharedfiles/filedetails/?id=3477279743). Steam users receive the required-item prompt. Manual EOC users must subscribe to or install and enable that framework separately.

The Dock Interactions icon can move when Diplomacy is locked or other interface mods are installed. Look for Dock Interactions in the top HUD menu rather than relying on its position beside Diplomacy.

## Preserved capabilities

EOC 2.5 retains Guided Recovery, bounded and reversible market tests, managed trade, shipping control, fleet templates, player-yard construction, reports, Personal Office access, named command intelligence, and all player-authority safeguards.
