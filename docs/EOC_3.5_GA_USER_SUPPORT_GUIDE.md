# EOC 3.5 GA User and Support Guide

EOC 3.5 GA is Build 304 / extension version 4.04. After loading a save, wait approximately 10 seconds for initialization, open **Dock Interactions**, and select **OPEN EXECUTIVE OPERATIONS CENTER**.

## Confirm the installed release

The startup notification should read:

`EOC 3.5 GA Build 304 | Assignment Feedback Consistency`

The X4 Extensions screen should identify EOC 3.5 GA Build 304 and version 4.04.

## Solution Planner and supply evidence

The Solution Planner uses X4's native owned-blueprint and production-library evidence for the exact module, method, output, workforce, recipe inputs, storage classes, and recommended module count. It remains advisory: EOC does not place modules, alter plots or build plans, hire builders, move cargo or credits, or bypass the vanilla Station Build Plan.

Supply collection remains explicitly triggered where governed. Selector changes redraw cached results, persistent cases require established evidence, and price/storage changes retain preview, confirmation, native application, and read-back boundaries. Raw Scrap remains excluded from conventional Supply recommendations.

## Raw-resource fleet management

For supported SOLID and LIQUID station resources, EOC can assign an eligible registered miner within the selected authority mode. An exact resource pin is claimed only after X4's native `MiningRoutine`, ware basket, and manual one-ware override read back successfully.

The recurring manager is deliberately slow and bounded: one station is reviewed per five-minute cycle, no more than one assignment change is allowed per cycle, and additional miners require repeated low-stock evidence. EOC never buys a ship, steals an assigned ship, creates resources, or converts ordinary traders into exact-resource miners.

## Assignment feedback

Explicit raw-source requests temporarily disable the action for one complete displayed refresh, suppress rapid duplicate callbacks, and report the selected ship and final pin result. Persistent records distinguish assigned-and-pinned, assignment in progress, pin not proven, blocked, source unavailable, and additional-miner-needed states.

## Reporting a problem

Report reproducible issues at https://github.com/razoreqx1/JK-Empire-Operations/issues with:

- EOC build/version
- X4 version
- Exact action and affected station, ware, or ship
- Relevant enabled mods
- Display resolution and UI scale for presentation issues
- A fresh exited-session `debuglog.txt`

EOC is designed not to make saves dependent on the mod. It adds no permanent custom ships, stations, wares, sectors, or assets required for a save to load.
