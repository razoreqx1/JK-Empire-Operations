# EOC 3.0 GA Release Notes

EOC 3.0 GA expands the Executive Operations Center with bounded, live operational intelligence while preserving player control.

## New and updated

- Live KPI sampling refreshes every 10 seconds only while the KPI Center is displayed.
- Filtering controls include meaningful **ALL** options for complete applicable datasets.
- Construction Progress provides compact all-station summaries and detailed selected-station module progress.
- Ware Shortages provides resource-level current, target, and shortfall details.
- KPI views are capped at eight visible data rows and report hidden-row counts.
- Automatic refresh preserves the player's visible scroll window and selected row.
- Case Trends and Empire Growth retain bounded live-session histories.
- Workforce, storage, logistics, and shipyard views use verified X4 data without inventing unavailable values.

## Safety and compatibility

EOC advises first and acts only within authority explicitly granted by the player. It does not provide free ships, bypass resources, or move credits without authorization. EOC supports X4 8.x and 9.x and does not require UI Extensions and HUD.
